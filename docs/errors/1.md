# Error `#1`: `mergePageParam` expects an object page parameter

This error happens when `mergePageParam` is set to a string shortcut and an
infinite query receives a primitive `pageParam`.

## Explanation

The `params`, `body`, `query`, and `headers` shortcuts merge `pageParam` into
an object. They cannot merge a primitive value such as a cursor string or a
page number.

```ts{5}
endpoint.toInfiniteQuery({
  params: { page: 1 },
  mergePageParam: 'query',
  getNextPageParam: response => response.data.nextCursor,
});
```

If `nextCursor` is a string, the `query` shortcut throws Error #1.

## Potential solution

Return an object from `getNextPageParam` when using a shortcut:

```ts
endpoint.toInfiniteQuery({
  params: { page: 1 },
  mergePageParam: 'query',
  getNextPageParam: response => ({ cursor: response.data.nextCursor }),
});
```

Or use a custom `mergePageParam` function for primitive page parameters:

```ts
endpoint.toInfiniteQuery({
  params: { page: 1 },
  getNextPageParam: response => response.data.nextCursor,
  mergePageParam: (params, cursor) => ({
    ...params,
    query: { ...params.query, cursor },
  }),
});
```
