# Error `#2`: Endpoint query client is not configured

This error happens when a query or mutation helper is created from an `Endpoint`
that has no `EndpointQueryClient`.

## Explanation

`Endpoint` can make regular HTTP requests with only an `HttpClient`. Its query
and mutation helpers — `toQuery()`, `toInfiniteQuery()`, `toMutation()`, and
`invalidateQuery()` — also need an `EndpointQueryClient` to manage the TanStack
Query cache.

```ts{4}
const endpoint = new Endpoint(configuration, httpClient);

// Throws Error #2 because no EndpointQueryClient was configured.
endpoint.toQuery({});
```

## Potential solution

Pass an `EndpointQueryClient` as the second constructor argument and an
`HttpClient` as the third:

```ts
const endpoint = new Endpoint(configuration, queryClient, httpClient);

const query = endpoint.toQuery({
  params: { page: 1 },
});
```

If the endpoint is intended only for direct HTTP calls, use `endpoint()` or
`endpoint.request()` and do not create query or mutation helpers.
