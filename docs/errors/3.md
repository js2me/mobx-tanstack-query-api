# Error `#3`: Endpoint HTTP client is not configured

This error happens when an `Endpoint` makes a request without an `HttpClient`.

## Explanation

`HttpClient` builds request URLs and executes HTTP requests. An endpoint cannot
be called through `endpoint()` or `endpoint.request()` without it.

```ts{4}
const endpoint = new Endpoint(configuration, queryClient);

// Throws Error #3 because no HttpClient was configured.
await endpoint.request({ page: 1 });
```

## Potential solution

Pass an `HttpClient` as the third constructor argument:

```ts
const endpoint = new Endpoint(configuration, queryClient, httpClient);

const response = await endpoint.request({ page: 1 });
```

When an endpoint does not use query or mutation helpers, it can be constructed
with an `HttpClient` as its second argument:

```ts
const endpoint = new Endpoint(configuration, httpClient);
```
